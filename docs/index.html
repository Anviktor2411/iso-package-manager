How it works

    
Everything lives in the project's GitHub repository: no accounts to create here, no server, and theme packs never contain code.

    

      
1
Make or upload
Build a pack in the editor, or drop an existing .ipmtheme.json / .ipmtheme.zip and a screenshot.

      
2
Finish on GitHub
A GitHub issue opens with your pack filled in. Drag the screenshot into it and submit.

      
3
Approval
A maintainer adds the approved label. A bot runs ipmtheme.py validate --strict, shrinks the screenshot and commits the pack.

      
4
In the shop
The theme appears here for everyone, with your screenshot and GitHub name.

    

    

      
Installing a theme in the app

      
Download the .zip (or .json) from a theme's details, then:

      
python tools/ipmtheme.py install my-theme.ipmtheme.zip

      
or copy the .json into %USERPROFILE%\.ipm\themes\ (Windows) or ~/.ipm/themes/ (Linux) and pick it in the Theme menu.
