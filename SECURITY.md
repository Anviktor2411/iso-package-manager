# Security Policy

## Supported Versions

This project is provided as-is. Security fixes may be released as needed.

## Reporting a Vulnerability

If you believe you’ve found a security issue:

1. Do **not** open a public GitHub issue with exploit details.
2. Instead, open a GitHub issue with minimal information and ask for a private contact channel, or contact the maintainer directly.

Please include:

- What you found and why it is a security issue
- Steps to reproduce (as safely as possible)
- Affected OS (Linux/Windows/macOS) and Python version

## Notes

This app downloads files from the internet. Only download ISOs from sources you trust.
